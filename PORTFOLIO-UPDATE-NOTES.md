## Install and check locally
From the `ct-sanjay-portfolio` folder:

```bash
npm install
npm run typecheck
npm run build
```

Then follow the existing `CLOUDFLARE-DEPLOY.md` instructions to preview and deploy.

The ZIP intentionally excludes `node_modules` and generated build files. Reinstall dependencies in your local project folder before building.
